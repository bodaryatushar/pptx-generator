Usage

Use it in any project

1. Install and point JSX at it

Any TypeScript or Babel project. No React needed.

npm i github:you/pptx-jsx

// tsconfig.json
"jsx": "react-jsx",
"jsxImportSource": "pptx-jsx"

2. Node, API route or CLI

Write the file, or return the bytes from an endpoint.

import { renderToFile, renderToBuffer } from "pptx-jsx";

await renderToFile(<MyDeck data={data} />, "deck.pptx");

// Express / Next.js route
res.setHeader("Content-Type", PPTX_MIME);
res.send(await renderToBuffer(<MyDeck />));

3. In the browser (React, Vue, …)

Preview with SVG and build the .pptx client-side, like this page does.

const slides = renderToSvg(<MyDeck />);
// React: <div dangerouslySetInnerHTML={{ __html: slides[0].svg }} />

const blob = await renderToBlob(<MyDeck />);
saveAs(blob, "deck.pptx");
